## About This Project
This repository contains our Art Resources Group Project. Our group works together to research, collect, and organize useful resources related to art, music, drawing, videos, and local culture.

Our website provides visitors with links to creative resources and opportunities to explore different forms of artistic expression.

## Project Goals
- Find useful and reliable art resources.
- Organize resources so they are easy to understand and access.
- Collaborate as a team using GitHub.
- Make individual contributions to the shared repository.
- Practice using Git commits and collaborative development.
- Create an accessible and responsive website using HTML and CSS.

## Website Sections
- **Art:** Explore famous artwork and museum collections.
- **Music:** Discover music and creative inspiration.
- **Drawing:** Learn drawing fundamentals and techniques.
- **Phoenix Culture:** Explore local art, murals, and entertainment in Phoenix, Arizona.
- **Videos:** Discover creative video content, including Apex – Chillwave Mix.
